What is Michelangelo?

Michelangelo is a free, open-source tool for creating interactive fiction — branching stories, text adventures, and narrative RPGs. It runs entirely in your browser and can be installed as a standalone app on any device.

Design your story visually with a node-based editor, add game mechanics like skill checks and inventory, then export a self-contained game file that anyone can play in a browser or terminal.
