Guide

Everything you need to build interactive fiction with Michelangelo.

Getting Started

Creating a Project

When you first open Michelangelo, you'll see the project menu. Click + New Project to create one. Each project starts with a small scaffold: a character creation node, a start node, and a second node connected by a choice.

You can also upload an existing project — either a single .json file or a folder of JSON files from a previous export.

The Layout

The editor has three panels:

  • Sidebar (left) — manage entities (attributes, items, etc.) and project settings.
  • Canvas (center) — your story graph. Drag nodes, draw connections, pan and zoom.
  • Inspector (right) — edit the selected node's text, choices, conditions, and effects.

The toolbar at the top provides save, undo/redo, node creation, validation, test play, and export controls.

The Canvas

Nodes

Every moment in your story is a node. Nodes appear as cards on the canvas. Click a node to select it and open it in the inspector. Drag to reposition.

There are two types of nodes:

  • Dialogue nodes — contain text the player reads and choices they can make.
  • Character creation nodes — present the player with character creation before the story begins.

The start node (marked with a badge) is where the game begins. You can change which node is the start node from the inspector or the context menu.

Connections

Edges connect nodes together. Each edge represents a choice or transition. To create a connection, drag from a node's source handle (bottom) to another node's target handle (top). This automatically adds a new choice pointing to the target node.

Region Comments

Region comments are colored rectangles you place behind groups of nodes to organize your canvas. Add them from the toolbar (Add → Region Comment) or the right-click context menu. Each region has a label, optional notes, and a color. Resize by dragging the edges.

Context Menu

Right-click on the canvas or a node to open the context menu:

  • On empty canvas: New Dialogue Node, New Character Creation Node, Paste, Region Comment (with color picker), Search Nodes.
  • On a node: Set as Start Node, Duplicate, Copy, Delete.

The Inspector

Select a node to see its details in the inspector panel on the right.

Dialogue Nodes

A dialogue node has the following fields:

  • Name — a label for the node (shown on the canvas card).
  • Text — the narrative text the player sees.
  • Image — an optional image path to display with the text.
  • On Enter Effects — effects that trigger when the player arrives at this node.
  • Choices — the list of options the player can pick (see below).

A dialogue node with no choices is a dead end — the story ends there. The validator will flag these so you can decide if they're intentional endings or missing links.

Character Creation Nodes

A character creation node lets the player customize their character before the story begins. It has a single Next Node field — the node to go to after creation is complete. The creation method (point-buy, dice roll, or preset) is configured in the sidebar under project settings.

Choices

Each choice on a dialogue node has:

  • Text — what the player reads as the option.
  • Target — which node the player goes to when they pick this choice.
  • Condition (optional) — a requirement that must be met for this choice to appear.
  • Effects (optional) — changes that happen when this choice is selected (give items, modify stats, etc.).
  • Required ability (optional) — an ability the player must have to see this choice.

Choices can be reordered with the up/down arrows in the inspector.

Entities

Entities are the building blocks of your game's mechanics. They are managed in the sidebar and referenced by conditions and effects on your choices.

Attributes

Permanent character stats like Strength, Intelligence, or Charisma. Each has a base value, min, and max. Used for stat checks on choices (e.g., "Strength ≥ 12").

Resources

Values that change during gameplay — Health, Mana, Gold, etc. Each has a default, min, and max. Effects can add, subtract, or set resource values.

Items

Objects the player can carry. Items have a name, description, and category. They can be stackable (player can hold multiples) or unique. Conditions can check item possession; effects can give or remove items.

Abilities

Skills or powers the player can acquire. Abilities can gate choices (a choice may require a specific ability to appear) and can be granted or removed by effects.

Traits

Descriptive tags on the character — personality, background, or status markers. Traits have a category (background, personality, etc.) and can be checked or modified through conditions and effects.

Companions

NPCs that can join the player's party. Companions have a relationship score that can be checked (“relationship with Aria ≥ 50”) and modified by effects. Conditions can test whether a companion is present.

Conditions & Effects

Conditions

Conditions determine whether a choice is available to the player. They are set on individual choices and evaluated at runtime.

ConditionDescription
Visited / Not VisitedWhether the player has been to a specific node.
Has Item / Not Has ItemWhether the player is carrying an item (with optional quantity).
Has Ability / Not Has AbilityWhether the player has an ability.
Has Trait / Not Has TraitWhether the player has a trait.
Has Companion / Not Has CompanionWhether a companion is in the party.
Companion RelationshipCheck relationship score with a companion (e.g., ≥ 50).
Attribute CheckCompare an attribute against a threshold (e.g., Strength ≥ 12).
Resource CheckCompare a resource against a threshold (e.g., Gold ≥ 100).
And / Or / NotCombine multiple conditions with logic operators.

Effects

Effects are changes applied when a choice is selected or when a node is entered (via "On Enter Effects"). Multiple effects can be stacked on a single choice.

EffectDescription
Add / Remove ItemGive or take items from the player's inventory.
Add / Remove AbilityGrant or revoke an ability.
Add / Remove TraitApply or remove a character trait.
Add / Remove CompanionAdd or dismiss a companion from the party.
Modify RelationshipChange a companion's relationship score by a delta.
Modify AttributeChange an attribute by a delta (e.g., +2 Strength).
Set AttributeSet an attribute to an exact value.
Modify ResourceChange a resource by a delta (e.g., −25 Health).
Set ResourceSet a resource to an exact value.

Testing & Export

Test Play

Click Test Play in the toolbar to play through your story from the start node. You can also right-click any node in the inspector and choose Play from Here to jump to a specific point (this enables debug mode, which shows extra state information).

Export Formats

The toolbar's export menu offers several output formats. When running with the development server, all formats are available:

  • Folder — a directory with HTML, CSS, and JS for hosting.
  • Single HTML — one self-contained HTML file.
  • JSON — the raw story data.
  • CLI Player — a terminal-based version of your game.
  • Desktop App — packaged for desktop.

When running as a static site (no server), use the Download Project button on the project menu to save your story as a JSON file.

Saving & Storage

With the development server (running npx vite locally), projects are saved to the file system. This is the best workflow for active development.

As a static site or PWA (including the hosted version at hungryrobot1.github.io), projects are stored in your browser's IndexedDB. Data persists across sessions but lives only in that browser. Use Download Project to back up your work as a JSON file, and Upload JSON to restore it.

You can also install Michelangelo as a PWA for an app-like experience with offline support. Look for the "Install as App" button on the landing page or project menu.
